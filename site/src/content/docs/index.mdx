## Install

<Tabs syncKey="install">
	<TabItem label="Homebrew" icon="homebrew">
		On macOS and Linux, Trealla is in Homebrew core. That gets you `tpl`, the library, the man page and the C embedding API.

		```sh
		brew install trealla-prolog
		```
	</TabItem>
	<TabItem label="Binaries" icon="download">
		Every release has prebuilt binaries for Linux, macOS, Windows, FreeBSD, NetBSD, OpenBSD, Haiku, Solaris and RISC OS, plus Cosmopolitan, WebAssembly and an Arduino Nano ESP32 image.

		<LinkCard title="Latest release" description="Download a zip for your platform" href="https://github.com/trealla-prolog/trealla-prolog/releases/latest" />
	</TabItem>
	<TabItem label="Source" icon="seti:c">
		It's plain C99 and a plain Makefile. On Debian-like systems:

		```sh
		sudo apt install build-essential git libedit-dev libffi-dev libssl-dev
		git clone https://github.com/trealla-prolog/trealla-prolog.git
		cd trealla-prolog
		make
		```

		See [building from source](getting-started/building/) for the options, and [other targets](getting-started/other-targets/) for Cosmopolitan, WebAssembly and cross-compiling.
	</TabItem>
</Tabs>

## What's inside

<CardGrid>
	<Card title="ISO at the core" icon="seti:prolog">
		Standard ISO Prolog with unbounded integers and rationals, UTF-8 atoms and strings of any length, and effectively unlimited arity.
	</Card>
	<Card title="Tabling" icon="random">
		Declare `:- table p/2` and left recursion terminates, repeated work becomes a lookup, and negation gets the well-founded semantics.
	</Card>
	<Card title="Constraints and coroutining" icon="puzzle">
		CLP(Z) and CLP(B), attributed variables with `freeze/2`, `dif/2` and `when/2`, DCGs, and delimited continuations.
	</Card>
	<Card title="Concurrency" icon="rocket">
		ISO threads, plus tasks, futures, engines and actors, with message queues and mutexes when you need them.
	</Card>
	<Card title="Batteries included" icon="server">
		HTTP client and server, sockets, URIs, CSV, JSON, regular expressions, crypto, and a blackboard for shared state.
	</Card>
	<Card title="Foreign functions" icon="setting">
		Call C libraries through libffi. Ready-made bindings cover SQLite, PostgreSQL, ZeroMQ, igraph, GSL, GLPK, PCRE2, cairo and raylib.
	</Card>
	<Card title="Embed it" icon="seti:wasm">
		A C API in `libtrealla.a`, WebAssembly for Go and JavaScript, and a two-way Python interface through Janus.
	</Card>
	<Card title="Runs almost anywhere" icon="laptop">
		Linux, Android, macOS, the BSDs, Windows, Haiku, Solaris and more, Cosmopolitan builds, and bare-metal ports to the Raspberry Pi 4 and ESP32.
	</Card>
</CardGrid>
